# Мультибот-платформа · LLM Memory Strategies

> Демонстрационная Streamlit-платформа, которая на одном экране показывает **три принципиально разных подхода** к управлению контекстом и памятью LLM: stateless, session и hybrid (FAISS). Все три бота работают параллельно и используют один и тот же OpenAI-совместимый API провайдера **AiTunnel**.

---

## 🎯 Назначение проекта

Современные LLM «забывают» всё между запросами. Способ, которым приложение **снабжает модель контекстом**, определяет качество ответов, расход токенов и пользовательский опыт. Этот репозиторий — наглядное пособие:

| Что хочется понять | Где это видно |
|---|---|
| Что будет, если не передавать историю вообще? | **Бот №1** |
| Как влияет полна�� история сессии? | **Бот №2** |
| Что даёт долгосроч��а�� память между сессиями? | **Бот №3** |

Откройте три вкладки, напишите один и тот же вопрос в каждый чат и сравните ответы.

---

## 🧠 Три архитектуры памяти

### Бот №1 · Stateless (без памяти)
- В API уходит **только последнее сообщение** пользователя.
- История в UI отображается исключительно для удобства оператора.
- Модель каждый раз стартует «с чистого листа».
- **Когда уместно:** одноразовые Q&A, классификация, извлечение сущностей, перевод.

### Бот №2 · Session (контекстная память)
- В API передаётся **вся история текущей сессии** браузера.
- Модель «помнит» всё, что было сказано в этой вкладке.
- Память живёт ровно до `F5` или нажатия «Очистить».
- **Когда уместно:** диалоговые ассистенты, уточняющие вопросы, отладка в режиме диалога.

### Бот №3 · Hybrid (сессия + FAISS)
- Сочетает оба подхода: top-k релевантных фактов из прошлых сессий + текущая короткая история.
- Эмбеддинги строятся **локально** моделью `all-MiniLM-L6-v2` (384 dim) — API-токены не тратятся.
- Хранилище FAISS персистентно на диске (`vector_store/faiss.index` + `metadata.json`).
- На каждом запросе формируется `system`-промпт с подборкой фактов из прошлых бесед.
- **Когда уместно:** персональные ассистенты, долгие проекты, техподдержка с историей обращений.

## 🖥️ Интерфейс

После запуска приложение открывается на `http://localhost:8501`.

**Боковая панель:**
- Выбор модели из реестра (`MODELS` в `src/llm/models.py`).
- `Temperature` 0.0 – 2.0, шаг 0.1.
- Глобальный сброс одной из четырёх историй (3 сессии + 1 долгосрочная).

**Главная область:**
- Три независимые вкладки со стримингом ответов.
- У Бота №3 — отдельная кнопка очистки FAISS-памяти и счётчик записей.

## 🚀 Быстрый старт (Windows)

Двойной клик по `start.bat`. Скрипт последовательно:

1. Останавливает уже запущенные `streamlit.exe`.
2. Чистит `__pycache__`, `.pytest_cache`, `.mypy_cache`.
3. Создаёт `.venv`, если его ещё нет.
4. Ставит/обновляет зависимости из `requirements.txt`.
5. Копирует `.env.example` → `.env`, если `.env` отсутствует.
6. Запускает `streamlit run app.py`.

```bat
start.bat
```

После старта **откройте `.env`** и впишите свой `AITUNNEL_API_KEY`. По умолчанию приложение слушает `http://localhost:8501`.

## 🔐 Конфигурация (`.env`)

Все параметры собраны в одном месте и читаются из `src.config`:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `AITUNNEL_API_KEY` | Ключ провайдера | — (обязательно) |
| `AITUNNEL_BASE_URL` | Базовый URL API | `https://aitunnel.ru` |
| `EMBEDDING_MODEL` | Локальная модель эмбеддингов | `all-MiniLM-L6-v2` |
| `EMBEDDING_DIM` | Размерность вектора | `384` |
| `TOP_K` | Сколько фактов подмешивать в system-промпт | `3` |
| `DEFAULT_TEMPERATURE` | Стартовое значение температуры | `0.7` |

### Принципы

- **OOP / Strategy.** Каждая стратегия памяти — самостоятельный класс с единым интерфейсом `BaseMemory.build_context()` и `BaseMemory.remember()`. Бот получает «готовое» хранилище через конструктор и не знает деталей реализации.
- **Single Responsibility.** `bots/*` — UI и сценарии, `memory/*` — хранилища, `llm/*` — интеграция с API, `ui/*` — визуальный слой, `utils/*` — общие хелперы.
- **DRY.** Общий потоковый чат-loop вынесен в `BaseBot._chat_loop()`; конкретные боты переопределяют только сценарий и `system`-промпт.
- **Масштабируемость.** Добавить нового бота = создать `src/bots/<name>_bot.py` (наследник `BaseBot`) + (опц.) новый класс памяти в `src/memory/`. Регистрация — одна строка в `build_bot_registry()`.
- **Конфигурируемость.** Никаких хардкодов в бизнес-логике: ключи, модели, размерности — в `.env` / `src.config`.

## 🩺 Диагностика

- **«⚠️ AITUNNEL_API_KEY не найден»** — не создан `.env` или ключ пустой. Скопируйте `.env.example` и впишите значение.
- **«❌ Ошибка аутентификации»** — проверьте ключ и баланс провайдера.
- **«❌ Ошибка сети»** — нет доступа к `AITUNNEL_BASE_URL` (проверьте VPN/прокси).
- **Бот №3 не «помнит»** — нажмите «Очистить долгосрочную память» и проведите новый диалог: факты появятся в `vector_store/metadata.json`.

## 📝 Лицензия и данные

- Все эмбеддинги считаются **локально** — никакие тексты не покидают машину.
- В API уходит только то, что вы отправили в чат, плюс выбранная модель и `temperature`.
- FAISS-индекс хранится на диске в `vector_store/` (исключён из git через `.gitignore`).
